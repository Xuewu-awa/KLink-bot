# 排序训练胜负方向修复

旧排序训练从胜/败两类样本随机选锚点，但一律推动锚点得分高于伙伴；败局锚点因此反向优化，且与 PairRank 的“胜局得分高于败局”评估相矛盾。现采样后统一 i=胜局、j=败局，再计算 log(1+exp(s_j-s_i)) 及反传。采样和权重平均规则不变，元数据增加 pairObjective=winner-minus-loser/v1（win 目标为 null）。

旧版在真实训练回归中未通过独立中心差分梯度检查，特定样本行重排也改变了更新方向。修复后 158 项检查通过：两种采样、两种切分种子、8 个单步案例的 96 个参数数值梯度检查，以及 1/12 轮训练的特定重排不变性。数值差分仅重建固定初始化并计算双精度排序损失，不复制反传公式；检查活动 W1 特征、全部 B1/W2，误差限 2e-6。每局标签保持固定，首次出现的对局顺序及留出集不变，仅调换第二次观测的行顺序。特定 win/BCE 合成案例的前后参数指纹完全相同。

原训练执行 46 项、归一化 50 项、留出集复验 200 项、准入 44 项和完整模拟器 1058 项通过，IR 加载 1709 张卡。DeepSeek 的 16 条源码引用已逐条核验；数学判定与集成由主 agent 完成。

这关闭了上一批负标签锚点方向待审项，保留旧报告和证据绑定，不升级游戏规则认证。旧 pair 模型须重新训练才能获得修复；现有策略入口仍拒绝 pair 目标。此合成测试不证明多单元采样全面正确或棋力提升；验证集无排序对时仍显示 0.5 的问题另列后续处理。
