# 动作数据未实现调用来源导出

本批补齐 teacher、replay、disposable planning 三阶段诊断来源。规划引擎在既有 finally 中汇聚来源，包括回调异常退出；跨规划计数采用 Int64，表示包含前缀重建的诊断工作量。

单 VM 和整局规划来源均限制 4096 个调用点，另行保留遗漏调用次数和采集失败次数。未调整游戏规则、数据版本4、教师契约或训练准入；来源不能豁免未实现调用。

DeepSeek 完成受限机械枚举，主代理核对原始输入后仅接受引用清单；其对部分 try 内语句的 finally_protected=false 标注不作为结论。输出不是规则权威。
