# 排序评估的零样本语义修复

旧训练和复验在没有同一对位、同一回合的胜负样本对时，显示并保存 50%，还据此判断编码信号。现统一显示“不可评估”，valAccuracy 与 bestValAccuracy 保存 null，新增 validationMetric、validationMetricStatus、validationMetricCorrect、validationMetricTotal。没有样本不再触发有/无信号推断；分档合计也不再伪装成 0%。胜负分类指标继续使用行数；排序指标使用实际可比较对数。模型摘要支持 null 并继续显示其余元数据。

新增 182 项合成回归通过：两种采样模式；同标签、不同对位、不同回合导致零对；两个有效排序对时真实 0%、50%、100%；训练保存后复验一致；伪造 99/99 元数据不能改变实际复验计数；缺少新增字段的旧模型仍重新计算。首次回归在旧生产代码上失败，随后补充了 24 项实际训练指标复验和摘要标签检查。既有方向 158、训练执行 46、归一化 50、留出集 200、准入 44 项通过；完整模拟器 1058 项通过，IR 加载 1709 张卡。

DeepSeek 仅清点源码引用，主 agent 核验了源码指纹、行数及全部 161 条字面引用，负责语义判断、修复与集成。此批只关闭上一批明确留下的零排序对评估问题，不认证卡牌或提升棋力。旧模型已保存的数字仍按原值展示，仅凭历史 0.5 无法判断其是否来自零分母，须复验。原有模型准入与运行时指纹约束继续生效；旧排序权重的方向错误仍需重训。历史证据绑定保持原样。
