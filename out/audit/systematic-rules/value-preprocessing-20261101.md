# 价值模型预处理隔离

旧实现先对全体样本计算均值与标准差，再按对局划分训练/验证，验证观测因此进入训练预处理。新回归对旧实现复现失败；修复为先按局切分，仅使用训练行拟合 scaler，再将冻结的参数应用于全部样本。训练及复验均拒绝不足两局的数据；模型元数据记录归一化版本及两组对局 ID。

使用真实 Train/Verify 和模型保存/加载路径：两个种子、win/pair 两种目标，覆盖回合末与决策前采样。只改变留出局的观测和标签后，归一化参数及权重逐值一致；常量特征、保存后的验证指标和单局拒绝也通过。预处理 46 项、准入 44 项、完整模拟器 1058 项通过；IR 正常加载 1709 张卡。

这是训练软件正确性修复，不认证游戏规则或对战强度。两局合成 pair 场景没有反标签训练配对，不证明排序学习有效。旧模型必须重新训练才能采用新 scaler。未提供 split-seed 时切分仍不确定；Verify 仍按传入种子重建切分，新增 ID 元数据仅作记录。人工反复按验证结果选择模型的偏差不在本轮范围。
