# 价值模型训练执行准入

旧实现允许零/负训练轮数、无可用胜负配对的排序数据，甚至已有配对单元但未实际抽到任何一对的情况保存初始化模型。旧版真实训练回归已失败。现要求 epochs 和 hidden 为正，排序训练集内至少有一个同对位同回合的双标签单元，并累计实际处理的行/配对数；累计为零时在保存前拒绝。元数据记录 processedTrainingUnits 和 trainingUnit。

新增 46 项检查通过，包含八类负例、首次输出不生成/已有模型不覆盖、win/pair 正常处理和保存加载复验、稀疏配对首轮为空但后续成功。归一化测试扩为四局，使排序训练含真实配对，50 项通过；原留出集复验 200 项、准入 44 项及模拟器完整 1058 项通过，IR 加载 1709 张卡。

处理数仅证明样本进入损失与反传流程，不证明非零梯度、权重改变、学习有效或棋力。验证集无排序对时仍沿用 0.5 占位，整数参数解析的非法字符串回退行为未改。排序目标中负标签锚点的梯度方向另列待审：当前公式对两类锚点均推动 si 高于 sj，本批仅修复执行准入，不认证排序学习正确性。旧模型不因本次修复自动获得认证；本项不属于游戏规则还原证明。
