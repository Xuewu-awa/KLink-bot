# 教师探测隔离（2026-10-30）

## 问题与实现

上一批原始贪心教师在正式引擎中执行 CanPlay、LegalPlayTargets 及可能失败的根动作尝试；这些步骤可能改变 targetOverride 等状态。最终根动作无法代表全部探测过程，造成100局全部拒绝。本批不改客户端规则查询语义，不删除快照字段，也不把探测状态复制回正式引擎。

现在保留两个仅执行确认根动作的正式引擎。每次决策新建第三个探测引擎，从相同种子、卡组和 first-index/v1 选牌策略开始，按已确认根命令重建前缀；比较时钟、随机状态及消耗次数、完整动作日志、现有 MatchSnapshot、观察与候选后，才调用 GreedyBot。只取成功根命令并丢弃探测引擎。两个正式引擎分别通过动作适配器执行同一命令，继续要求执行成功、日志、随机和快照一致。根命令不匹配、正式执行拒绝、重建分叉或故障均终止，整局缓冲不写入。

这定义了新教师策略 `greedy-isolated-prefix/v2+first-index/v1`，不承诺与原始有副作用的贪心整局行为等价。探测中的错误、未支持操作和未实现调用仍参与整局准入；诊断计数包含前缀重复执行的工作量，不能解释为正式对局事件次数。既有信息性调用白名单保持不变。

数据头升级到版本2，校验器拒绝旧版未隔离教师。成功局还要求规划决策数等于标签行数 N，前缀根执行数等于 N*(N-1)/2。每局前缀根执行上限250000，另保留5000行、4096候选/行和200000候选/局上限。超过任何上限拒绝整局。

## 边界

重建避免依赖不完整的私有状态克隆；现有比较仍不是完整对象图、队列、委托或所有静态状态的等价证明。候选是结构超集而非合法掩码，ChooseOne、完整目标空间及非默认部署落点继续显式开放。此次为模拟器训练接口软件修复，未新增整卡规则认证，未训练动作网络，也未使用历史回放作规则权威。

逐决策从头重建的累计成本为二次增长；本实现首先提供有工作量上限的隔离基线。后续优化必须保留独立回归，不能以跳过探测校验或恢复部分字段替代隔离。

## 验证

回归保留原始英日/日澳快攻、种子1的查询副作用复现，并要求新流程越过原先的分叉。故障注入覆盖探测字段写入、RNG消耗、动作日志清空和自动出牌队列污染；后续重建、正式状态与标签须与基线相同。另检查重建分叉、探测VM未支持操作和工作量超限拒绝，以及旧契约和缺失规划计数不能通过数据校验。

完整1004项BotSim、32项动作数据检查、28项既有训练准入检查和16项矩阵测试通过。新数据通过verify-actions校验。未训练动作模型。机器记录：[规划隔离检查](../../out/training-readiness/oracle-planning-isolation-20261030.json)。
