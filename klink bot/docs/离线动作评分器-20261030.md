# 离线动作评分器（2026-10-30）

本批将已准入的动作标签接入小型行为克隆评分器，验证训练、保存、加载和消费契约。它尚不驱动自对弈，不代表规则审计完成或 AI 强度达标。

## 输入与目标

- 观测复用 `StateEncoder.Spec`，当前 745 维，使用行动方视角。
- 候选复用 `MainActionFeatures.Spec` 的 18 维特征；每行候选数可变，仍是结构超集。
- 隐层计算 `tanh(W_context * observation + W_action * features + bias)`，共享输出权重得到候选分数，再对同一行 softmax。上下文在非线性之前与动作交互，避免共享线性上下文在 softmax 中抵消。
- 监督目标为教师候选索引的交叉熵。卡牌 ID、回合号、候选索引、胜负和标签不进入网络；索引只用于损失和第一项平分决胜的评估。
- 同行特征完全相同的候选必有相同概率；当前特征没有完整单卡身份及效果，无法表达所有动作差异。

模型格式为 `KLink.MainActionScorer/tanh-v1`，与既有价值网络格式分开。契约绑定观测/动作规格、教师、结构候选语义、数据 SHA-256、所有输入 JSON/向量及 KLink.Bot/NNTrain 两个二进制的 SHA-256。默认教师与固定末项教师不可混用。重编译导致指纹变化时需重新生成数据。

## 命令与验证

```powershell
dotnet run --project tools/NNTrain -- action-model-selftest
dotnet run --no-build --project tools/NNTrain -- dump-actions --games 10 --seed 1 --choose-one-policy last --out <目录>/actions.jsonl.gz
dotnet run --no-build --project tools/NNTrain -- train-actions --data <目录>/actions.jsonl.gz --out <目录>/action-model.json --epochs 3 --hidden 16 --lr 0.01 --split-seed 1
dotnet run --no-build --project tools/NNTrain -- verify-action-model --data <目录>/actions.jsonl.gz --model <目录>/action-model.json
```

训练前先验证整份动作数据及准入清单，不降低原有双引擎、日志、RNG、状态快照和整局拒绝门槛。按游戏 ID 确定性划分，至少两个已准入游戏，约 20% 游戏留作验证，训练中不使用验证行。当前内存训练器显式限制 20,000 行/2,000,000 候选，超限报错，不截断。模型保存加载后逐行要求概率完全相同。

报告包括训练前后交叉熵、验证交叉熵、Top1、均匀候选交叉熵、始终结束回合的 Top1 基线及教师特征碰撞行数。`verify-action-model` 复核绑定的同一份数据和整局划分，尚非跨数据集泛化测试接口。小样本同教师评估只能验证管线，不能证明对战能力。

自测以中心差分独立核对四组梯度，检查受控损失下降、候选置换、特征碰撞、上下文交互、模型头、有限值、输入指纹与教师拒绝、整局划分、保存加载、请求/离线评分一致及元数据不进入网络。

## 信息边界与剩余工作

BotSim 对左右两个视角分别使用非零且不同的 90 维卡向量，改变敌方手牌和双方牌库的身份/攻击/防御/选择字段，完整动作请求必须不变；改变自己手牌身份则必须改变请求。这只是指定区域的不泄漏回归。敌方潜伏场上单位、历史信息、情报等完整可见性语义尚未证明；当前敌方手牌即使 CardSeen 也不编码身份，可能少用合法信息。

结构候选包含不合法动作，且引擎拒绝可能伴随状态写入，不能直接选择最高分并在拒绝后盲目重试。接管对局前仍需闭合合法动作掩码、动作身份/效果表达、场外目标及部署落点，并验证完整可见性和选择回调契约。本批不增加任何卡牌或原生规则认证，不使用其他类似项目或历史回放作为规则权威。

DeepSeek 对上一批固定末项 20 局进行机械清点，主 agent 独立从原始压缩文件复算：2,460 行、187,748 候选，其中 427 行教师候选特征被同行其他候选共享。该计数只说明表示能力缺口，不能直接推导 Top1 的绝对上限（第一索引平分规则可能与教师相关）。最终当前构建冒烟数字及文件指纹见 `out/training-readiness/action-model-smoke-20261030.json`。
