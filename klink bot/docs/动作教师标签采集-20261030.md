# 主动作教师标签采集 v1

本批新增双引擎动作标签采集和 gzip JSONL 校验，未接入动作网络训练。教师使用现有 GreedyBot，选牌策略为 first-index/v1；另一引擎只通过 MainActionPolicyAdapter 执行匹配的根动作。标签观察为行动方视角，候选仍为结构超集，不是合法动作掩码。

每一步要求根命令唯一匹配、应用成功、回合/胜负/RNG、动作日志增量及现有 MatchSnapshot 相同。下一步开始前还比较候选、观察和快照。现有快照包含隐藏卡的序列化状态，但不覆盖全部引擎/VM私有状态、队列、委托或完整对象图；通过这些检查只表示有限的软件一致性，不是规则认证或完整状态等价证明。

每局最多缓冲5000行，单行4096候选，全局200000候选；整局结束且执行健康检查通过才写标签。任何缺失/歧义候选、执行拒绝、故障、未结束或一致性失败都拒绝整局，包括已缓存的前缀。导出头绑定状态/动作规格、教师/候选契约及输入JSON、模拟器和采集器二进制哈希；清单绑定压缩数据哈希和逐局统计。verify-actions检查这些绑定的结构和文件完整性，不自动证明当前安装资料与历史输入相同。

```powershell
dotnet run --project tools/NNTrain -- actions-selftest
dotnet run --project tools/NNTrain -- dump-actions --games 100 --seed 1 --out <输出目录>/actions.jsonl.gz
dotnet run --project tools/NNTrain -- verify-actions --data <输出目录>/actions.jsonl.gz
```

## 实测发现的阻塞

最终固定种子1、100局MetaDecks试采：0局准入，100局拒绝，写入0行。88局首先发生root_snapshot_mismatch，首次差异片段均涉及targetOverride；另12局首先遇到未覆盖的ChooseOne。拒绝局合计曾缓冲566行，全部未写入。unfinished在这里是主动停止后未结束的结果，不能据此判为100局死循环。

真实英日/日澳快攻、种子1回归显示：教师和重放动作日志及RNG相同，卡牌BlueprintVariables却不同。源码中GreedyBot调用CanPlay；指令目标可用性检查HasPlayableOrderTarget会保留targetOverride写入。直接执行最终根动作不会自动重放教师此前全部查询。本批没有删除该字段、忽略差异或修改规则以放行；这是一条采集流程缺口，不能把模拟器现象升级为客户端规则证据。

最初未比较MatchSnapshot的20局试采曾接收7局747行；该批不满足最终检查，不能作为合格动作训练数据。最终100局导出返回2，verify-actions拒绝空集；未生成动作模型。

## 验证与下一步

新增4组内核回归：三种子混合单位整局/四类动作唯一匹配；缺失、重复、根执行拒绝及RNG/日志/快照分叉；三种缓冲上限；真实卡组查询副作用。完整1003项内核测试通过。动作数据28项检查通过，含整局拒绝不泄漏、实际单位测试局压缩往返、同种子标签逐字节复现及损坏字段/清单/哈希拒绝。单位测试局只作接口测试，不代表MetaDecks可准入或训练强度。既有28项训练准入及49项审计工具测试通过。

下一批先隔离教师查询与真实执行：保留客户端规则查询的副作用语义，设计可验证的教师规划边界或独立探测引擎，确认被拒动作不会污染真实执行；随后补ChooseOne及其标签契约。不能直接复制targetOverride来掩盖其它探测状态变化。单卡规则认证、完整合法掩码、默认落点以外部署和完整目标空间仍开放。
