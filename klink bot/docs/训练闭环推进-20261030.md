同种子10局全部结束，准入3->6局、样本80->189，本次Debug采样用时13.4->1.2秒；这是同组观察值，不是普遍性能保证。12个双侧/三牌/初始激活状态回归及完整981项通过。

仍有4局拒绝：Red Devils入口2局、Ki-61 Hien入口1局、新到达的MakeLiteralText1局。两张卡已确认无自身反射函数，但基类空脚本不能直接证明完整默认派发无效果，暂不放行。机器记录：[进展](../../out/training-readiness/gotcha-policy-progress-20261030.json)。

## 已处理：训练数据准入

`NNTrain dump` 现在检查对局结束/胜方、IR 已加载、VM 异常、未支持指令、真实未实现调用、观测非有限数和空样本。先缓冲整局，只有通过检查才写入该局样本。未知诊断标记默认阻止准入。

`<local-ran:...>` 是已执行本地函数的标记，前线满员/敌方占领是正常动作拒绝；这三类保留在报告中，不单独作为未实现规则。它们伴随的 VM 错误仍会拒绝对局。

导出生成 `.quality.json`，记录逐局原因、种子/卡组、计数、输入指纹及二进制 SHA-256。`train` 和 `verify` 拒绝缺失、不一致、被修改或没有可用样本的清单。旧数据必须重新生成。有拒绝对局或无样本时 `dump` 返回 2，已接受部分仍单独可验证。诊断通过仅表示未发现这些执行错误。

```powershell
dotnet run --project tools/NNTrain -- admission-selftest
dotnet run --project tools/NNTrain -- dump --games 10 --seed 20261030 --out <输出目录>/data.bin
```
