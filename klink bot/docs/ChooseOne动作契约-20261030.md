# ChooseOne 动作契约（2026-10-30）

## 解决的问题

隔离后的教师仍会打出选择卡，但旧候选枚举跳过所有 ChooseOne 卡，导致同种子1的100局有67局因缺少根候选而拒绝。本批仅补训练动作接口，不改变规则引擎或卡牌 IR，不将软件一致性检查解释为新的整卡规则认证。

## 实现

MainActionCommand 增加 ChooseOne：-1 表示非选择卡；选择卡使用从0开始的原生选项索引。每张手牌按静态 ChooseOneOptionCount 展开各分支，每分支保留无目标和场上目标组合。枚举不调用 CanPlay、WhichChooseOne、合法目标查询或效果执行，仍是结构超集。

根执行先检查索引和所属手牌位置，再把索引写入 CardInstance.ChooseOne，之后只调用一次 PlayCard。该字段与 BlueprintVariables 中同名派生字段独立；WhichChooseOne 的目标标志副作用仍由既有引擎处理，不在适配器中复制。合法索引但被规则拒绝的动作仍可能修改状态，拒绝后必须丢弃整局，不能重试或声称回滚。

贪心教师在 PlayCard 前记录当时索引，避免效果执行改变字段后误记命令；没有增加分支搜索或改变其策略。前缀重建与正式执行复用同一根分派。

主动作请求版本2；动作特征 main-action/v2 从16维扩为18维，新增 index+1（非选择卡为0）和选项总数。数据格式版本3，教师契约 greedy-isolated-prefix/v3+choose-one-explicit/v1+first-index/v1。校验器拒绝旧契约、非Play动作携带选择、非法范围、分支与特征不符。旧动作数据必须重新采集。

## 验证与边界

先复现旧枚举缺少分支的失败回归，再验证两侧候选不修改状态、不泄漏隐藏手牌；高级皇家研究的两个分支分别生成 ACTIVE SONAR / BLETCHLEY PARK，与手工设置原生索引后直接调用引擎的快照和轨迹一致。越界索引在根调用前拒绝；M1高炮选择卡的教师前缀重建保持一致。这些是现有卡IR的接口回归，不是对客户端当前资产版本的重新认证。
