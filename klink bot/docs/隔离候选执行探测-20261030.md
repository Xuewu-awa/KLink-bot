# 隔离候选执行探测（2026-10-30）

本批新增独立的候选执行诊断，不修改卡牌规则，不接入训练样本、模型评分或正式对局策略。目标是先检查候选能否在当前模拟器执行，为后续合法动作边界调查提供故障分类。

## 执行契约

`IsolatedActionProbe` 接收种子、双方卡组、已确认的根动作前缀及正式参考引擎。每个候选新建一个引擎，从头执行同一前缀；仅在快照、动作日志、回合/RNG/待选状态及候选请求一致后执行该候选。完成后丢弃引擎，不把后继状态交给策略。

返回三态：`Accepted` 是当前模拟器根动作返回 true；`Rejected` 是健康执行返回 false；`Unknown` 包含重建分歧、前缀拒绝、VM/未支持操作/真实缺失调用、待选、异常和依赖嵌套选牌。选牌重建使用固定 first-index 策略，根动作中发生嵌套选牌就保持未知。信息性调用标记的允许范围与既有训练准入一致；不增加忽略项。

正式参考引擎的快照、日志、RNG/回合、候选请求和诊断计数在批前批后对照；发现变化使整批已有标签失效为未知。默认最多128候选、4096前缀根动作、20000累计前缀重放；超限在开始探测前返回批错误，不静默截断。

## 验证与边界

5项新增定向回归覆盖正反序、候选状态丢弃、正式引擎不变、重建分歧、故障和嵌套选择、工作上限及正式状态污染后整批失效。全部1012项BotSim、49项动作数据、31项模型检查、16项矩阵测试通过。这些是软件契约测试与故障注入，不是游戏规则修复的权威对照证明。

DeepSeek对限定的4份源码副本完成机械清点。主agent核对全部副本与当前源码SHA-256，以及60条摘录对应的精确行，并独立复核关键路径；摘录一致不能自动认可所有语义说明，更不能认证游戏规则。

当前仍有以下限制：

- 引擎实例独立，但静态IR/默认值及卡牌定义对象仍处于同一进程；没有进程隔离。
- 快照与请求未覆盖全部VM私有状态；正式参考引擎过去发生的选牌适配器故障无法仅由引擎恢复。
- 返回true不证明指定目标确实被采用，也不证明候选集合覆盖所有真实合法动作。未知也绝不等于非法。
- 工作上限限制候选和前缀数量，没有独立墙钟超时；长前缀全量重放尚不适合直接用于大规模训练。
- 有界两卡组实测不证明全卡池、完整隐藏信息边界或模型对战强度。

审计矩阵在批末重建，已有局部证据及过期原因继续保留，不重置指纹、不增加整卡认证。下一批优先为未知补候选命令和缺失调用来源，并核实目标执行语义；完成这些前不把诊断三态当作可靠合法掩码。
