# 训练根动作的明确指令目标校验

本批修复 `MainActionPolicyAdapter.ApplyRoot` 中非选择型定向指令的具体目标检查。旧入口只确认“存在可用目标”，因此即使请求指定友方、空目标或其他不满足条件的对象，也可能执行指令。不存在的非零目标 ID 现在直接拒绝，避免退化成无目标请求。

## 权威依据与修复边界

核对安装文件提取的完整函数 JSON，并记录相应原始 uasset/uexp 与解析文件 SHA-256：

| 函数 | 已核对条件 |
|---|---|
| Desert Rats / CanPlayFromHand | GetTargetedCard、对方阵营、IsSameSideUnit；失败 enemy_unit |
| Critical Hit / CanPlayFromHand | IsUnit 且总防御低于 MaxDefense；失败 damaged_unit |
| Air Corps Ferrying / CanPlayFromHand | IsSameSideUnit(己方)；失败 friendly_unit |
| BP_Logic / CanPlayCardFromHand | 候选绑定 targetOverride → 单卡 CanPlayFromHand → 有效 targetedCard → 清空绑定 → CanSelectAsTarget |
| cardsCheckFunctions / CanSelectAsTarget | 对象有效、场上位置、隐蔽检查等公共条件 |

精确 StatementIndex 与文件指纹见[机器记录](../../out/training-readiness/explicit-order-targets-20261030.json)。这些解析内容是游戏文件的派生证据，不表示当前客户端与全部提取资产的版本关联已经闭合。

训练入口在原有 CanPlay 可用性查询后、花费/动作记录/效果前，针对无 ChooseOne 的定向指令调用已有 CanTarget，复用单卡谓词及公共目标门槛。CanPlay 的可用性查询契约保持不变。旧 public PlayCard、选择牌及单位部署继续待审，未扩大为全部出牌路径的修复。

CanTarget 只恢复临时 targetOverride 绑定，其他蓝图查询状态写入仍可能保留；拒绝请求不具有一般性的纯查询或原子回滚保证。既有原生目标谓词兜底也未获得完整认证。

## 验证结果

新增四组回归在旧 a299a05 入口上为三组失败、一组通过；恢复修复后，完整 1018 项 BotSim、49 项动作数据检查及 31 项模型检查全部通过。

新增场景覆盖双侧友方/总部/零/不存在/手牌/未揭示隐蔽目标，受伤与未受伤单位、友方与敌方单位，以及可用性查询、临时绑定恢复和无目标指令。拒绝时核对指挥点、源卡位置与当前目标、动作记录、RNG、单位防御/压制/位置，不把未比较的 BlueprintVariables 或 VM 计数宣称为无变化。

双侧 10 个 Desert Rats 夹具：4 个有效敌方目标接受，6 个友方/空/不存在目标拒绝，拒绝时单位效果不变。真实游戏规则依据来自上述函数，夹具仅检验实现。

同种子 1、同两卡组的 12 个教师前缀共 543 候选：126 执行成功、407 明确拒绝、10 未知（6 嵌套选牌、4 未实现调用诊断），正反序完全一致；双向 1086 引擎、7444 前缀根动作、单次 3.874 秒。它只是模拟器执行诊断，未接入训练准入或模型策略，不能当作完整合法掩码。

构建输出 Data JSON 使用原工作区既有、通过 IR 契约的输出逐字节复制，避免独立检出行尾差异改变指纹；未绕过指纹守卫。实际加载输入、二进制和日志 SHA-256 均入机器记录。

DeepSeek 清点结果由主 agent 核验四份输入 SHA 和 84 条源码引用：81 条准确，3 条注释行号错误已排除。其 16 条写入、19 条返回及 14 条未决记录仅用于定位；语义判断、权威比对、集成和推送由主 agent 完成。
