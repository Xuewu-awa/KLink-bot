# 目标卡组覆盖率分析

> 输入：用户提供的 22 套卡组码
> 数据：`deck_code_ids.json`（码→卡名）+ `card-effects.json`（卡名→效果调用）

**为什么要算这个**：一张卡只要有一个外部调用没实现，它在对局里就是错的。
所以真正决定工期的是「要覆盖这些卡组，得实现多少个调用」，不是全卡池百分比。

## 2. ⭐ 结论：要实现多少个调用

这些卡组用到的调用**并集 = 177 个**（全局共 1494 个不同调用）。

| 范围 | 调用数 | 说明 |
|---|---|---|
| 全部所需 | **177** | 实现这些 → 上表所有卡组 100% 正确 |
| 其中在全局前 100 | 85 | 高频，几乎所有卡都用 |
| 其中在全局前 300 | 142 | 主力 |
| **其中在全局 300 名之后** | **35** | ⚠️ 长尾：只为某一套牌服务 |
